# ⚡ Fake Hacker Terminal

A stylish fake hacker terminal built using **HTML, CSS, and JavaScript**.
This project simulates a real command-line interface with interactive commands, cyberpunk aesthetics, and terminal-style animations.

---

## 🚀 Features

* Interactive terminal commands
* Neon cyberpunk UI
* Real-time command responses
* Fake hacking simulation
* Linux-style commands
* Smooth scrolling terminal
* Responsive design

---

## 🛠️ Built With

## 💻 Available Commands

| Command    | Description                 |
| ---------- | --------------------------- |
| `help`     | Show all commands           |
| `about`    | About the developer         |
| `skills`   | Display skills              |
| `projects` | Show projects               |
| `contact`  | Contact information         |
| `date`     | Current date and time       |
| `pwd`      | Show current directory      |
| `whoami`   | Display current user        |
| `ls`       | List files                  |
| `hack`     | Start fake hacking sequence |
| `clear`    | Clear terminal              |

## Run and Test

From the repo root, start the dev server:

    npm run dev

Open http://localhost:3000/public/fake-hacker-terminal/ (keep the trailing slash so style.css and script.js load).

Run the browser check (needs Node.js and Playwright with Chromium):

    node tests/course/r60-t043.mjs

The check starts its own local server and tests the empty and error states: empty input, whitespace-only input, an unknown command, and names like `constructor` and `__proto__` must all show "Command not found" and must not print JavaScript internals. It also checks that `help` and `pwd` still work afterwards, that `clear` and later errors still work, and that there are no failed requests or page errors. It exits non-zero on any failed assertion.
